# Enough

A calm Home Screen web app for iPhone that helps you use your phone less while
keeping the essentials one tap away.

- **Essentials:** a short list of apps that open instantly (Messages, WhatsApp,
  Maps, Calendar by default; choose from a list or add any app link).
- **People:** the few people you always want to reach, with Call, Text and
  WhatsApp buttons.
- **Paused apps:** Instagram, YouTube, TikTok, X and anything else you choose
  open only after a breathing pause (5–30 seconds) and an honest answer to
  "what's it for?", with a gentle nudge for each answer.
- **Today:** how many paused apps you opened, how many times you chose not to,
  and a 7-day view.
- **Intention:** one line for what matters today.
- **Set up your iPhone:** a step-by-step guide for the settings that actually
  enforce it (hiding Home Screen pages, grayscale, Screen Time limits, Downtime
  with WhatsApp and Messages always allowed, a Focus, and a Screen Time
  passcode). A web app cannot block other apps; only iOS Screen Time can.

Deep links: `#pause-instagram` (any app id) opens the pause for that app;
`#setup` opens the guide.

App links (like `whatsapp://`) open the app only if it's installed. Everything
is stored on the device; nothing is sent anywhere.

Install: open `https://<user>.github.io/games/enough/` in Safari, then
Share → Add to Home Screen.
