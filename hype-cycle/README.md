# Hype Cycle

Breakout set in an AI startup. You run the hype for Max Scale, the (entirely
fictional) CEO of HyperMind. Bounce the hype into buzzword bricks to pump the
company's valuation. One HTML file, no build step, no dependencies.

**How to play:** drag anywhere to move the paddle and tap to launch. Cyan
buzzwords take two hits. Clear the board to close the funding round; each round
runs faster.

**Scoring:** every buzzword adds to the valuation, shown as a "+$20M" pop-up
with a cash-register sound. Break several bricks without touching the paddle
for a combo multiplier, up to 8x. Losing a ball costs 10% of the valuation.
Valuation milestones (seed round, Series A, unicorn, decacorn and up) trigger a
banner and a fanfare, and the news ticker runs headlines and CEO quotes as you
play.

**Power-ups** fall from some bricks:

- **$$$** funding round: wider paddle for 12 seconds
- **FORK** fork the model: every ball splits into three
- **SAFE** safety pause: slower ball for 9 seconds

On a keyboard: the arrow keys move, Space launches, P pauses.

Host the folder on any static host and use Safari's **Share → Add to Home
Screen** to run it full screen on iPhone.
